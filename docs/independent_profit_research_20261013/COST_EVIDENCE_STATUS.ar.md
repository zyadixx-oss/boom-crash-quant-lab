# حالة دليل التكلفة

فُحصت سجلات سابقة على الحساب المتصل الموجود باستخدام أدوات قراءة محدودة، مع تعطيل التداول. لم تُقرأ أو تُنشر أسماء الحساب أو أرقام التذاكر أو الرصيد أو الربح والخسارة. ملفات الرسوم والحجم الخام وتفاصيلها محفوظة محليًا في مجلد خاص مستبعد منGit.

- اختيار1أكتوبر2024→1أكتوبر2025 بتوقيت خادمHistorySelect لم يظهر صفوف رسوم مطابقة للرموز العشرة. هذا لا يثبت غياب جميع التكاليف أو مجانية الفترة.
- الاختيار اللاحق من1أكتوبر2025 إلىTimeCurrent أظهر مكونات رسوم قابلة للفحص. تحقق مستقل أعاد حساب الحقول المحفوظة، دون نشر قيمها أو أعداد السجلات الخاصة.
- لا يثبت ذلك ربط العقد أو العملة تاريخيًا، ولا تجميع جميع رسوم الصفقة المقابلة، ولا الانزلاق أو التعبئة. لا تعمم مواصفات اليوم على فترةيناير–مايو2025.

لذلك يبقى`cash_net=null` و`cost_verified=false` و`execution_verified=false`. نتائج البحث الجديد، إن حُسبت، ستسمى حركة سعرية شرطية بعدالسبريد وافتراض الانزلاق؛ لا صافي ربح نقدي مثبت. يتضمنJSON المرافق بصمات تقارير التحقق الخاصة وحالاتها فقط.
