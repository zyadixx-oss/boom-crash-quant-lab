# بروتوكول تحقق تنفيذ تاريخي بالتكات

أربع سياسات ثابتة: Boom 500 وCrash 500، على M1، فرضيتا ما قبل الانفجار وما بعده بإعدادات الجولة صفر. نختار أول 50 إشارة مؤهلة زمنيًا لكل سياسة قبل حساب نتائج الصفقات. الإشارات الخام تشمل ما قد ترفضه قاعدة صفقة واحدة لاحقًا.

التقسيم نفسه 60/20/20، والتشخيص على جزء التحقق فقط؛ الاختبار النهائي مغلق. نطلب نافذة الاحتفاظ الكاملة، أربع دقائق، لكل إشارة. التغطية المطلوبة تكة أصلية لكل ثانية وتطابق سعر الدخول مع افتتاح الشمعة. نحتفظ بالأخطاء والفجوات والنتائج المجهولة.

الطلبات محددة قبل القياس ومجزأة إلى 1000 ثانية كحد أقصى، وبفاصل ثانيتين على الأقل؛ الحد الأعلى 500 طلب، والتوقف عند خطأ API دون إعادة محاولة تلقائية. يحفظ كل رد أصلي وطلب وإيصال.

المقارنة تشخيص لاختيار التنفيذ، وليست اختبار ربحية مؤهلًا. التكلفة 0.10 ATR مفترضة دون إثبات CFD أو bid/ask أو تنفيذ حساب. لا تغيير لإعدادات الاستراتيجية، ولا ترقيتها، ولا أمر تداول، وجميع بوابات التداول الحقيقي false.
