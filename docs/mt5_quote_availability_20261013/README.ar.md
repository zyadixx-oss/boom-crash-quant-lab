## الملفات والتحقق

لكل التقاط مجلد `receipts/<prefix>/` يحتوي `<prefix>_receipt.tsv` و`<prefix>_ticks.tsv` و`verification.json`. نُسخت ملفات TSV ببايتاتها الأصلية دون ترتيب أو حذف تكرار أو تقريب أسعار أو ملء فجوات. يُحفظ ما أعادته المحاولة المختارة فقط، وفق `SELECTED_ATTEMPT_ONLY`؛ لا يُدعى حفظ كل مصفوفات retries.

يمكن إعادة التحقق من أي نسخة دون منصة أو اتصال سوق:

```python
from pathlib import Path
from scripts.verify_mt5_quote_export import verify_export

receipt = Path("docs/mt5_quote_availability_20261013/receipts/<prefix>/<prefix>_receipt.tsv")
report = verify_export(receipt)
assert report["status"] == "QUOTES_VALIDATED_COVERAGE_NOT_PROVEN"
assert not report["errors"]
```

تظهر الحدود الأولى والأخيرة غير المرصودة، والتكرارات ذات الملّي ثانية نفسها والفواصل الزمنية في كل تقرير. عدم وجود فاصل أكبر من 5 ثوانٍ لا يثبت غياب تكات مفقودة أو اكتمال الدقيقة.

## حدود الدليل

كل نافذة تثبت إتاحة مقطعها القصير فقط؛ لا تثبت إتاحة يوم كامل أو الفترة التاريخية كلها أو أطول تاريخ متاح. مواصفات العقد المحفوظة حالية عند الالتقاط، ولا تثبت رسوم 2025/2026 أو التمويل أو الربط النقدي التاريخي. أسماء الشركة والخادم خضعت لفحص محلي، دون إثبات مستقل لهوية الحساب أو مصادقة مصدر الوسيط.

**cost_verified=false، execution_verified=false، profit_tested=false، full_tick_coverage_verified=false.** لا تحتوي الحزمة سجلات مالية خاصة أو تعبئات أو نتائج استراتيجية، ولم يُعد حساب ربح محرك الحملة. تبقى الرايات الثماني للتداول الحقيقي `false`، ولا أوامر أو صفقات منفذة.
