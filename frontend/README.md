# نطاق — شارت Boom وCrash مع CRT

واجهة عربية مستقلة تتصل بقناة Deriv العامة؛ لا تحتاج حسابًا أو مفتاح API أو خادم المشروع لعرض الشارت.

## التشغيل

يتطلب Node.js 22.18 أو أحدث. من مجلد `frontend`:

```bash
npm ci
npm test
npm run typecheck
npm run build
npm run dev
```

افتح `http://127.0.0.1:5173`. للنشر الثابت استخدم محتويات `dist`.

## قراءة CRT

- يكتشف الرموز المتاحة من `active_symbols`، ثم يشترك في 1000 شمعة للفريم المختار وM5 للتحليل.
- مرجع النطاق هو آخر H1 مغلقة بتوقيت UTC، ويشترط 12 شمعة M5 متصلة.
- على Boom: سحب أسفل CRL. على Crash: سحب أعلى CRH. العمق المقبول 0.10–0.65 من ATR(14) السابق.
- استعادة بإغلاق داخل الحدين خلال شمعة السحب أو الشمعتين التاليتين.
- MSS والإزاحة وFVG يجب أن تجتمع على نفس إغلاق M5، ضمن الاستعادة وثلاث شموع تالية. التاريخ يحفظ الملاحظات حتى بعد انتهاء الإعداد أو إبطاله.
- تظهر العلامات عند معرفة الحدث بعد الإغلاق؛ لا تدخل الشموع المفتوحة أو بيانات المستقبل في حساب النموذج. فجوات البيانات تمنع اختلاق المرجع أو ATR.
- CRH وCRL و50% والمنطقة المرجعية والعلامات قابلة للإخفاء. عرض M1/M5/M15/H1 لا يغير H1/M5 التحليلية.
- محور الرسم UTC، والملاحظات بتوقيت الرياض. انقطاع الاتصال أو تأخر البيانات يظهر صراحةً مع إعادة المحاولة. حداثة الشارت وحدها لا تعني حداثة تحليل M5؛ إغلاق الشمعة وحداثة التحليل يتبعان بث M5 نفسه. لا يُرقّى آخر snapshot جزئي من التاريخ اعتمادًا على بث آخر.

العلامات ملاحظات وصفية، ولا تثبت احتمال انفجار أو ربحية. تبقى `LIVE_TRADING=false` و`READY_FOR_LIVE=false` و`LIVE_ALLOWED=false` و`OPENED_TRADES=false`. يرسل الموقع طلبات بيانات عامة فقط؛ لا يحتوي على طلبات حساب أو تداول.

يغطي `npm test` السببية والفجوات والإبطال والانتهاء والتبديل والتنظيف والتأخر وإعادة الاتصال ومنع طلبات الحسابات والتداول. مصدر الرسم Lightweight Charts من TradingView.
