# بيانات نقل تاريخية مستقلة لفحص النموذج المتعلم

المصدر: WebSocket العام الرسمي لـ Deriv. تم تنزيل البيانات فقط؛ لم تُحسب إشارات أو نتائج تداول.

الفترة: **2025-10-09 11:08 UTC إلى 2026-04-07 11:08 UTC حصرياً**، أي 180 يوماً. آخر دقيقة: 2026-04-07 11:07 UTC.

تأكدت الأسماء من `active_symbols`: معرّفا API هما `BOOM300N` و`CRASH300N`. المحاولة الأولية بالأسماء المختصرة انتهت قبل تنزيل أي تاريخ، وحُفظ فشلها في `initial_alias_failure.json`. جرى تشغيل الجامع نفسه دون تعديل بعد تصحيح المعرفين.

لا توجد فجوات أو تكرارات أو شموع خارج شبكة UTC الدقيقة. جميع قيم OHLC موجبة ومنتهية وبترتيب صالح؛ لم تُستعمل أي تعبئة اصطناعية. كل رمز احتاج 260 طلباً تاريخياً وطلب تعريف رمز عام واحد، بلا أخطاء في جولة الجمع الناجحة.

`acquisition_audit.json` يحفظ الفترة والبصمات والتحقق من بقاء ملفات البيانات السابقة وكود الجامع دون تغيير. جميع مسارات الإثبات محمولة ونسبية إلى جذر المستودع. ملفات الأسعار الأصلية والمطبعة محفوظة محلياً ومستبعدة من Git.

هذه عينة تاريخية أقدم للتحقق من نقل النموذج، وليست اختباراً مستقبلياً. تضمنت المحادثة القديمة ادعاء تصنيف سابقاً لـ Boom 300 لم يُثبت هنا؛ لذلك لا تُوصف هذه الرموز بأنها لم تُر مطلقاً. اختيار نموذج العائد يجب أن يتجمد قبل تقييم أي نتائج على هذه العينة.

الأعلام `LIVE_TRADING=false`, `READY_FOR_LIVE=false`, `LIVE_ALLOWED=false`, `OPENED_TRADES=false` بقيت كلها false. لا توثيق حساب ولا أوامر تداول؛ الجمع لا يفترض تكاليف أو أسعار تنفيذ أو أرباحاً.
